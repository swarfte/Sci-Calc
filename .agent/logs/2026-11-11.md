# 2026-11-11

## Windows 更新安裝時自動關閉執行中的 app

- 任務摘要：使用者反映 app 內更新後，安裝程式會出現「是否關閉應用程式」
  詢問頁，需手動多一步。經確認採用「保留安裝精靈＋自動關閉」方案。
- 檔案檢視：`windows/installer.iss`、`lib/features/update/`（downloader、
  viewmodel、view）、`.github/workflows/build-release.yml`。
- 決策與假設：
  - 在 installer.iss 加 `CloseApplications=force`（Restart Manager 自動關閉），
    不改 Dart 端啟動邏輯。
  - 不加 `RegisterApplicationRestart`：避免 Restart Manager 自動重啟與
    postinstall「啟動」項目重複開啟兩個实例；重啟交由 Finish 頁的啟動項目。
  - force 對手動執行安裝檔的使用者也生效（一致行為）。
- 檔案變更：`windows/installer.iss`（[Setup] 加一行 directive＋註解）。
- 使用者可見行為：更新安裝時 app 被安裝程式自動關閉，不再出現詢問頁；
  安裝完成後由「啟動」checkbox 開啟新版。
- 依賴變更：無。
- 驗證：本機無 Inno Setup，無法編譯 .iss；directive 語法依官方文件確認，
  實際編譯由 CI（build-release.yml）驗證。
- 後續風險 / 待辦：下次 tag release 後實際走一次 2026.8.8 → 新版的更新
  流程確認；force 關閉會丟掉 app 記憶體內未儲存狀態（對計算機可接受）。
